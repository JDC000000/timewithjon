# Security policy

Please report security problems **privately** through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability):
open the repository's **Security** tab and choose **Report a vulnerability**.

Please don't open a public issue or pull request for a vulnerability, and don't test against the live sites
(`timewithjon.com`, `staging.timewithjon.com`, `timewithjon-proto.vercel.app`) beyond what is needed to show the
problem. Never access or keep guest data.

In scope: this repository's code, its CI workflow and the deployed sites built from it. Only the latest `main` is
supported. We aim to reply within 7 days.
